# Brand Color Theme

The primary brand color is **lime green** (`#32CD32`). Our products are eco-friendly, and the green theme reflects that.

- Use `lime-*` Tailwind classes for primary brand elements (buttons, links, accents, hover states, icons)
- Use `green-*` for gradients and secondary green accents
- Keep `red-*` ONLY for error states, validation messages, and danger actions
- The homepage gradient uses `from-lime-400 via-lime-500 to-green-500`
- Always prefer green/lime for CTAs, active states, and brand highlights
